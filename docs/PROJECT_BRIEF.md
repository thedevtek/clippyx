# Clippyx — Project Brief

## One-liner
Clippyx is a keyboard-first, local-first clipboard manager for Windows, designed for developers who copy code, commands, URLs, and text throughout the day.

## Vision
Make retrieving and reusing copied content almost instantaneous. A developer should be able to open Clippyx, find an item, and paste it in under two seconds.

## Target user
- Software developers on Windows
- Developers who frequently copy code, commands, logs, SQL, URLs, and snippets
- Users who want clipboard history without an account or cloud dependency

## Product principles
1. **Fast:** the quick window opens immediately and search is responsive.
2. **Keyboard-first:** core tasks work without a mouse.
3. **Local-first:** clipboard history remains on the device.
4. **Privacy-first:** capture exclusions, pause capture, expiry, and clear-history controls.
5. **Small and focused:** avoid turning the MVP into a general productivity suite.
6. **Reliable:** clipboard monitoring must not interfere with normal copy/paste.

## Product positioning
A developer-oriented clipboard history tool—not an IDE, code editor, or cloud snippet service.

## MVP success criteria
- Captures text clipboard changes while enabled.
- Displays recent entries in newest-first order.
- Search returns relevant items quickly.
- User can copy an item back to the clipboard and paste it.
- Global shortcut opens the quick window.
- App remains available in the system tray.
- User can pin, delete, clear, pause capture, and configure retention.
- No clipboard data is transmitted over the network.
- App can be installed and uninstalled cleanly.

## Explicitly out of scope for MVP
- Cloud sync or accounts
- Image clipboard history
- HTML/RTF clipboard history
- OCR
- AI features
- Team sharing
- Plugin marketplace
- Cross-platform support
- Automatic clipboard transformations
